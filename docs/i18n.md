# 多言語化（i18n）— llove

> **かみ砕いた説明**: この文書は、llove の画面に出てくる言葉を、いくつかの言語（まずは英語と日本語）で切りかえられるようにするしくみの設計をまとめたものです。
> たとえば、学校の標識を「日本語」と「英語」の二枚を貼り替えられるようにしておくイメージです。画面の言葉をプログラムの中にバラバラに書くのではなく、ぜんぶ一つの「言葉のリスト」のファイルにまとめておきます。そのリストの一つひとつには、あだ名のような短い呼び名（名札）を付けておきます。プログラムは「この名札の言葉を出して」とお願いするだけなので、リストのほうを日本語版・英語版とそろえておけば、あとから新しい言語をかんたんに足せます。
> 言葉の意味の一覧は [用語集（GLOSSARY.md）](GLOSSARY.md) を見てください。

llove はデフォルト英語、日本語同梱で出荷されます。表示文字列はすべて
`llove/i18n/locales/<lang>.toml` に置かれており、コードからは `t("key")`
で参照されます。

## ロケールの選択順

1. CLI フラグ `--lang ja`
2. 環境変数 `LLOVE_LANG=ja`
3. システムロケール（`ja_JP` → `ja`）
4. 既定の `en`

## 使い方

```bash
llove --lang ja demo --scenario scada     # 日本語で表示
llove --lang en demo --scenario scada     # 英語で表示
LLOVE_LANG=ja llove demo --scenario scada # 環境変数経由
```

## コード内での参照

```python
from llove.i18n import t, set_locale

set_locale("ja")
print(t("ui.button.pause"))               # → ⏸ 一時停止
print(t("scenario.scada.phase2"))         # → フェーズ 2 — ドリフト...
```

## 新しい言語を追加する

1. `llove/i18n/locales/<lang>.toml` を新規作成
2. `en.toml` と同じキー構造で全て翻訳
3. `from llove.i18n import available_locales` で自動的に検出される
4. PR → 完成

不足しているキーは自動で `en.toml` にフォールバックします。

## 略語の正規化

`temp` のような曖昧な略語は **使わず** に full word（`temperature`）で記述
することがプロジェクト方針です。サンプルコードとして読まれることを考慮
しています。
