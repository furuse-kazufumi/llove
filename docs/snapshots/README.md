# Snapshots

This directory holds **previewable artifacts** that GitHub renders inline:

- `demo.html` — single-file HTML snapshot generated by `llove export`
- `demo.svg` — terminal screenshot (Textual's SVG export)
- `demo.cast` — asciinema recording of `llove demo`

Regenerate locally with:

```bash
llove export --source mock://demo --html docs/snapshots/demo.html --duration 5
```
